# line. A leading slash anchors a pattern at the repository root, a trailing slash matches folders
# only, and `*`, `?` and `**` match as in .gitignore. The last pattern that matches a file or one of
# its folders decides; a pattern starting with `!` takes a file back in. Patterns match in any case,
# so a folder spelled otherwise on a disk that ignores case (Intake/ for intake/) stays out too.
