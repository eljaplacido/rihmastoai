# The factory is called Rihma

The owner chose **Rihma**, Finnish for a hypha, a fungal thread. A hypha grows toward what is
needed, branches, carries nutrients and signals in both directions, and repairs itself. The
name is a living *throughline*: one thread from a business need to the running service, with
feedback flowing back along it.

"Gnomon Factory" was the working name. Gnomon remains the engine (the harness every model
call goes through). Rihma is the factory built on it.

- **Name check, 2026-11-22.** A web search found no software company, app or platform called
  Rihma; the near hits were spelled differently (Rihal, RISMA, Rhema+). This is not a
  trademark clearance. Before using the name publicly, search the exact word in the PRH
  trademark information service and EUIPO's database (or TMview).
- **Rename.** Docs, published pages and the command name are renamed in one pass when v1 is
  finished, so the running work is not disturbed. The repository folder keeps its path.
